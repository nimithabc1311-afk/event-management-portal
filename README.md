# 🎉 Event Management Portal

A fully functional **Event Management Portal** built using **HTML, CSS, and JavaScript**.

**Developed by: Nimitha BC**

---

## 📌 Features

- 🎪 **View All Events** — Browse all events with details like date, venue, price and seats
- 🏷️ **Event Categories** — Filter by Music, Technology, Sports, Food, Art, Business
- 📝 **Register for Events** — Register with name, email, phone and ticket count
- 🎟️ **My Registrations** — View and cancel your registrations
- 🔧 **Admin Dashboard** — Add new events, delete events, track revenue
- 🔍 **Search & Filter** — Search events by name, venue or description
- 💰 **Auto Price Calculator** — Total fee calculated based on tickets selected
- 💾 **Data Persistence** — All data saved using localStorage
- 📱 **Responsive Design** — Works on mobile and desktop
